// English text for the editor, in the layout of Valve's resource/*_english.txt files:
//   fn:<function>            the name the simple interface shows for a particle function
//   fn:<function>#tip        a line on what it does ("fn:<list>|<function>" where a name is in two lists)
//   set:<setting>            a setting's name ("set:<function>|<setting>" for one function only)
//   set:<setting>#tip        a line on what it does
//   set:<setting>@<value>    a name for one of its values, for settings that pick from a few
//   field:<number>           particle fields, for settings that pick one ("output field")
//   unit:<kind>              what follows a number of that kind (see particle_inputs.txt)
//   mat:<parameter>          a material parameter's name ("mat:$basetexture"), with #tip and @<value>
//   shader:<name>            a material shader's name, with #tip
//   snd:<key>                a soundscape or soundscript key, block or CHAN_ constant's name
//   vtf:flag:<NAME>          a texture flag's name, with #tip; vtf:format:<NAME>#tip and vtf:res:<tag>
// Keys match without regard to case. Written for vomit-tools from the VDC articles and what the
// preview does; not Valve's text.
